# Fabric Employee Analytics

## Project Overview

This project demonstrates an end-to-end Employee Analytics solution using Microsoft Fabric.

## Technologies Used

- Microsoft Fabric
- OneLake
- Lakehouse
- Data Pipeline
- PySpark
- SQL
- Power BI

## Project Architecture

Employee.csv
↓
Lakehouse
↓
Pipeline
↓
employee_transformed
↓
Semantic Model
↓
Power BI Dashboard

## Repository Structure

- Dataset
- SQL
- Notebook
- Pipeline
- PowerBI
- Screenshots

## Dashboard Features

- Total Employees Card
- Total Salary Card
- Department-wise Salary
- Department Split Pie Chart
- Department Slicer
- Employee Details Table
